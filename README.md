# Mac mini AI Server

A personal project exploring secure AI automation using a Mac mini.

## Project Overview

This project aims to enable remote task execution and automation through Discord and AI-assisted development tools.

## Planned Features

- Remote command requests through Discord
- System status monitoring
- AI-assisted task automation
- Secure remote administration

## Development Status

Currently under development and testing.

## Security

This repository contains public project information only.
Application source code, credentials, and private infrastructure details are maintained separately.
